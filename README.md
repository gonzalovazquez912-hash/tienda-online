# Tienda Online (demo)

Aplicación web simple para venta de comercio online hecha con **HTML + CSS + JavaScript puro**.

## Funcionalidades

- Catálogo de productos.
- Búsqueda por nombre.
- Filtro por categoría.
- Carrito de compras con persistencia en `localStorage`.
- Cálculo automático de subtotal, envío y total.
- Formulario de checkout con validaciones básicas.

## Cómo usar

1. Abre el archivo `index.html` en tu navegador.
2. Agrega productos al carrito.
3. Completa el formulario y confirma tu pedido.

## Estructura

- `index.html`: estructura de la app.
- `styles.css`: estilos.
- `app.js`: lógica del catálogo, carrito y checkout.
